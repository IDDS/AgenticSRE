# 历史观测变化整理（试验性）

`summarize_changes` 将各 Pod 的 CPU 使用率及链路 P95 前后变化分别排列，并保留正负方向、缺失值和样本数量。排序只是为人工或模型阅读提供辅助，不是故障定位排名，也不证明相关性或因果关系；低采样数和请求构成变化会影响结论。

输入只包含观测摘要，不接收或读取故障真值。使用历史事故时间划分窗口属于回放设计，不能作为在线检测时间。独立的评估程序必须在输出冻结后核对标签，并分别报告对象和服务层级的匹配。

该模块当前尚未接入诊断主流程。已知样本开发回放中，添加变化摘要后首位对象与标签一致；另一日期的独立单例未命中，不能据此宣称准确率提升。部署使用前仍需多样本、不同数据源和缺失数据条件下的独立验证。
