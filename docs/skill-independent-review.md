# Agent+Skill 独立角色复核

Agent+Skill 在生成最终结论和根因身份后，由独立角色再次调用模型审查已提交观测。该角色复用 `RCAJudge` 的质量阈值、引用检查和候选审核规则，结果参与置信度校准，并保存到结果、策略历史和 Ontology。它可以使用同一模型，不代表独立模型、人工审核或因果正确性的形式证明。

## 输入和引用

根因对象必须匹配命名投影中的 cluster、namespace、kind、name、UID 和 resourceVersion。复核同时检查已提交的普通 JSON、清单查询中与这些对象对应的观测；后续版本、实例或共同状态字段冲突不能被入口目录筛掉。完整原始 trace 保留，超范围资源行单独计数。非空且未覆盖的工具输出形成复核缺口；应用日志不能冒用空清单回执。

相同状态的重复读取只向模型提供一份主事实。相等判断保留 UID、版本、全部投影状态、来源及信号类型，仅排除采集时刻。原始 obs-ID、采集时间和主事实映射仍进入提示、输入哈希及复核记录；Ontology 继续保留全部原始观测。不同版本或状态不合并，不以重复读取增加独立证据源。

复核使用 E-ID 引用主事实，候选审核使用原始 obs-ID；主事实不改写，引用可回到实际观测。有效引用只说明来源可解析，并不自动证明语义蕴含。根对象观测本身必须被引用，模型提出的检查计划、候选自报状态和历史知识不能代替本次事实。

## 候选排除与失败处理

没有可观测的宿主类型化反证检查时，候选的 `contradicted` 判断降为 `uncertain`；原模型意见和限制原因同时保留。已经声称排除的候选没有通过独立核验时，整体仍须审核。例如，当前副本为 0 不能排除之前发生过资源驱逐，selector 匹配也不能排除端口映射错误。本链路尚未为任意自由文本机制提供通用反证器。

新工具执行由宿主记录 UTC 采集时间。旧记录缺少时间时，不用对象创建时间或重放时间填补。异常时间值、解析错误、身份缺失、范围冲突、投影不完整、未知输出、无效引用和候选漏审都保留为缺口；拒绝收据也必须能够严格 JSON 序列化。

复核阶段向现有客户端传递网络期限及零重试配置，宿主期限到达后不接受迟到结果。真实客户端须返回独立的 `JSONCompletion` 传输收据，确认正常 `stop`、响应完整且没有拒绝或工具调用；生成 JSON 中的同名字段不能伪造收据。没有可验证收据的旧适配器保持待审。每次复核只关联本次新增事件中的收据，不能复用前一次成功结果。

## 有界执行和结果字段

当前实现最多检查 128 条命令、6 个候选；结构化复核快照最多 12,000 UTF-8 字节，完整消息最多 32,000 字节，接受的复核输出最多 12,000 字节。结论最多 500 字符，推理正文最多 3,500 字符，加上范围和引用映射后最多 4,000 字符。超限会要求补证或人工复核，不裁掉尾部后宣称完整审核。宿主只发起一次复核调用，输出预算 1,800 tokens，沿用该 Agent 配置的调用期限。

| 字段 | 含义 |
|---|---|
| `judge` | 独立角色质量评分、事实目录、引用、候选审核及阻断原因 |
| `judge.skill_review` | 输入哈希、字节数、源观测/主状态数量、别名、时长、调用及停止收据 |
| `diagnosis_status` | 审核条件满足时为 `reviewed`，其余为 `requires_review` |
| `diagnostic_strategy.independent_reviews` | 与本次候选及缺口关联的独立复核轨迹 |
| `automation_gate` | 本链路仍固定拒绝动作准入，保留 `skill_action_contract_required` |

审核通过只表示该次有限证据复核满足条件。当前工作没有建立 Agent+Skill 对象动作的执行准入，也未实现自动补证重规划或原生自愈闭环。验证结果及未通过样本见[本轮验收](validation/skill-independent-review-20261027.md)。
