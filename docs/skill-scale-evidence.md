# Agent+Skill 缩零场景证据核对

对独立复核结果，宿主额外核对同一范围内被审核引用的 Service、Endpoints 和 Deployment：对象身份与版本、采集时间、Service selector 与工作负载模板、期望副本为零、没有就绪端点，以及定向采集的候选唯一性和空 Pod 结果。范围、引用、审核收据或结构缺失时，记录明确阻断项，不用模型文字补全缺失事实。

结果记录在诊断策略的 `scale_zero_evidence` 中，并在过程页展示。`eligible_for_further_review` 只表示这些有限观测满足进一步审核条件；模板匹配不是运行期所有权或因果证明，不能说明缩零的触发者，也不自行授权执行。通用诊断动作门禁仍保持原状。受控自动恢复编排可在服务端重新核对这些证据、独立审核和唯一目标策略后，为指定 Deployment 的恢复动作构造内部契约；它仍须通过既有历史、审批、动作安全与业务验证等门禁。外部请求不能通过传入标志获得该内部契约。

同一对象可能被不同来源的投影读取多次。若模型明确引用了多条记录，只有各条记录的 UID、资源版本、删除状态及投影中的 `spec`、`status`、`subsets` 均一致时，才将它们视为同一状态；不合并缺失字段，也不将重复读取计作独立证据。记录保留各条引用的 E-ID，任何身份或状态冲突仍阻断。

此前一次真实缩零故障的保存记录经过只读重放，因旧工具输出缺少采集时间、存在未覆盖输出等原因仍被阻断；未补造时间，也没有调用模型或执行动作。正向案例和边界回归使用受控数据，不能计为新故障注入或证明总体准确率。过程页远端 Chromium 验证使用实际页面和候选脚本，接口响应使用测试替身，检查了阻断、结果未知、成功核验、读失败、历史切换及无写请求。详情见[验证记录](validation/skill-scale-evidence-20261028.md)。
