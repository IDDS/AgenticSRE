# 真实故障复核输入预算

在隔离候选和非生产测试床进行真实缩零：基线 20/20、故障期 0/5，对照健康；诊断记录了空端点和目标 Deployment 零副本。首次故障调查的独立复核快照为 17776 字节，超出原有 16000 字节上限而未调用模型；自动恢复被门禁阻断，实验控制器恢复业务。

在不调用模型的只读重放中，同一份调查重建后的快照为 17778 字节。将快照上限设为 24000 字节后，完整提示为 40298 字节，低于既有 48000 字节提示上限；此重放没有产生审核结论或授权动作。最终代码将快照上限提高到 24000 字节，保留单条观测、完整提示、输出、提供方完成凭据和其他审核门禁；超限仍拒绝，不截断后冒充完整复核。

最终快照在远端隔离容器通过 828 项定向测试、2573 项完整测试和页面渲染检查。第一版新增测试夹具因未达到原总预算而失败，调整为多条观测后重新通过。

第二次非生产真实缩零的基线为 20/20、故障期为 0/5，诊断再次识别到空端点与零副本。最终复核输入为 15851 字节，首次独立审核取得完整模型结束凭据，补证后的最终审核在八秒时超时，独立审核和诊断门禁继续阻断自动恢复。由于该次输入低于原上限，不能据此证明扩大预算提升了实时成功率。两次故障均由实验控制器恢复；第二次恢复后三个业务窗口各 10/10、对照健康，围栏释放，目标恢复 1/1。没有替换生产服务，也没有完成自主诊断自愈验收。
