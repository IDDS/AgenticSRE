## 范围与冻结协议

本轮使用实际 `Pipeline.run → run_rca`，执行假设生成、验证计划、证据迭代与假设重排、关联分析、最终报告、质量审核、置信度校准及按需补查。领域取证代理替换为冻结快照读取适配器：指标和告警读取该组原始观测，Trace 读取同一对象的已保存窗口 Span；日志、Kubernetes 状态等未保存的数据明确返回不可用。没有用当前集群状态替代历史现场，也没有伪造工具响应。

这覆盖了配置启用的实际推理流程，**不是完整在线取证或生产根因准确率验收**。关闭历史记忆、协作优化、图定位、自演化和恢复动作；启用关联和质量审核，补查按真实闭环逻辑决定。两版具有相同的冻结领域观测、查询、模型、预算及评分标签，仅使用各自镜像中的告警证据包和 RCA 入口。

样本在调用前固定为上一轮的 `case-00`、`case-03`、`case-08`、`case-09`、`case-12`、`case-20`、`case-23`、`case-28`。覆盖六个有故障阶段、同 Pod 的错误/延迟两组和上一轮错引样本，共 8 个组、16 次配对运行；这是开发集的代表性选择，不是独立留出集。阶段名、控制计划、评分标签及未来恢复结果不进入模型。每组交替新旧版先后顺序，不因结果失败而挑选重跑。

模型为 `deepseek-v4-pro`；temperature=0、thinking=false、自动重试 0、单次输出上限 2,048 token、请求上限 45 秒、每次 Pipeline 最多 16 次模型请求及 180 秒共享模型预算、最多两轮取证迭代。供应商用量和完成状态直接记录每个实际响应；缺失用量保留未知，不能用字符数估算补齐。领域取证不调用模型，因此这里的总用量不包括生产领域代理的模型摘要成本。

`contract.json` 在首个 RCA 调用之前冻结两版消息输入与外置标签的摘要、实现摘要、镜像、样本选择、调用顺序和预算。最终输出先持久化，再读取标签检查；不按输出调整标签。应用内部机制并未在本批快照中被独立采集，`mechanism_accuracy` 固定为空，不把模型自评分或目标对象命中率当根因准确率。

## 定位并修复的问题

`case-00-candidate` 的第 4 次模型调用是实际 `CorrelationAgent` 的关联分析，使用应用原有的 1,536 输出 token 上限。供应商回执为 `finish_reason=length`、`completion_status=truncated`。原 `DeadlineLLMClient` 没有强制检查完成状态，截断文本被交给后续报告；最终质量审核为 `needs_review=false`。这不是根据文字猜测截断，而是由原始调用回执确认。

修复后，RCA 使用的 `DeadlineLLMClient` 为每次响应采集完成回执，拒绝截断、拒答、过滤、工具调用、状态未知及空文本。完整性失败记录保留在本次 RCA 的模型客户端中；最终复核前再次检查，后续审核高分不能清除前序失败。存在此类失败或已记录的模型调用超时时，最终结果明确要求人工复核，置信度上限为 0.65，并阻止自动学习和自动恢复。原报告文字与观测继续保存供审核，不伪造纠正后的机制结论。其他使用普通 `LLMClient` 的入口（包括 Skill 路由）未在本轮改动。

远程初始回放器回归 46 项通过。修复版定向回归 **71 项通过**；全量回归 **1,355 项通过，0 失败、0 错误、0 跳过**，JUnit 记录耗时 233.565 秒。新增反例覆盖“看起来完整的 JSON 但回执为 length”、拒答/过滤/工具调用/未知状态/空响应，以及后续高分审核不能覆盖前序失败。实际 `run_rca` 集成回归在开启自动学习与低阈值自动恢复的配置下验证：截断关联分析被拒绝、人工复核已创建、学习和恢复均未执行。定向与全量测试相互包含，不累加为不同用例数。

## 尚未解决的诊断质量问题

首轮 `case-00-candidate` 仅有错误率和延迟观测，却写出“处理能力不足或存在阻塞”，原质量审核未将其列为无依据断言；`case-12-candidate` 将应用侧 `ProbeError` 指标进一步解释为 Kubernetes 存活/就绪探针连续失败，快照未提供相应探针配置或事件。`case-20-candidate` 把稳定延迟归因于 CPU 不足或节点 CPU 争用，快照中没有 CPU 观测；该例虽进入人工复核，报告文字仍存在越界推断。

这些反例说明：有界上下文能改善输入事实传递，但不能单独保证推理和模型审核正确。完成状态拦截解决的是不完整输出被采用及其自动动作风险，不是自动修正所有无依据根因。本次没有把模型自评升级成独立真值，也没有用针对上述词句的替换规则伪装成通用根因修复。下一项质量工作需要让机制结论逐项关联支持观测和缺失证据，并在独立事故集上验证；原始告警 ID 的最终逐字引用校验也仍需单独完善。
