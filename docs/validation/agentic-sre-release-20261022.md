## 本次行为

调查对象绑定集群、命名空间和资源 UID，支持观测引用、控制器谱系及来源声明比较。假设生成保留引用与反证，调查按缺口有界补证；历史读取区分空结果、失败及超时。模型硬拒绝、截断或无效最终报告会保留未完成状态，要求人工复核并阻断自动学习与恢复。

告警压缩隔离冲突资源实例，校验原始输入与分区全量守恒及最高严重级别。人工编辑后，以当前扫描文件为权威结果；旧审核版本不可继续用于新分区。恢复与发布均校验版本，保留在途请求记账，不以重新加载页面重启审核。

能力与约束分别见[告警压缩](../alert-compression.md)、[诊断策略](../diagnostic-strategy.md)、[历史检索](../history-retrieval.md)及[对象模型](../operational-ontology.md)。
