# 候选机制支持的保守复核门禁

真实业务缩零实验中，独立审核将模板标签匹配、Deployment 零副本和 Pod 不存在，分别误称为支持 Service 选择器与 Pod 标签不匹配、以及 Pod 崩溃或未就绪。原调查因其他未核实候选而阻断自动恢复，但这些错误支持判断不能作为机制验证。

在当前缺少独立绑定事故时间窗和因果关系的类型化契约时，针对描述中明确出现的上述两类机制，即使审核模型返回 supported，也将该候选标为 uncertain、保留原始模型意见，并阻止被断言的候选自动通过。规则基于有限的中英文描述匹配，不能覆盖所有措辞或其他机制；也会保守阻断确有相关结构观测的候选，后续应以类型化对象、时序及因果证据替代。没有将缺少 Pod 视为机制反证。

将该真实调查的已记录候选与审核响应进行只读重放，两个错误支持均转为 uncertain，未再次调用模型，也未改写原调查。最终快照在远端通过 832 项定向测试、2577 项完整测试及页面渲染检查；修改后未重新注入故障，不能视为自主自愈验收。
