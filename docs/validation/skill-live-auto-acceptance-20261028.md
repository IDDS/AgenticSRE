# Agent+Skill 真实缩零故障与审核预算验证

本轮在隔离候选实例和非生产测试床进行了真实故障实验。候选实例使用已验证源码，禁用旧直接写入和自动学习，开启受控自动编排并保留审批要求；自动恢复历史为空。健康诊断完成后，独立看门狗就绪，实验控制器对单副本 Deployment 执行身份和版本约束下的真实缩零。诊断请求包含业务观测和目标范围，不包含注入原因或预设答案。

基线业务请求 20/20 成功，对照健康；故障期间业务请求 0/5 成功，对照健康。Agent+Skill 在 24.611 秒内完成诊断，绑定到了被缩零的 Deployment 身份，采集记录包含空端点、零个选中 Pod 和唯一模板候选；该绑定不证明缩零触发原因。诊断置信度为 0.618，低于自动执行的默认 0.9 阈值。

实际自动编排记录为 `blocked`，阻断项为 `independent_review_required` 和 `diagnosis_gate_not_allowed`；隔离实例的真实动作记录为零。实验控制器随后恢复原副本数，业务恢复连续三个窗口各 10/10 成功、对照健康；原 Deployment 保持 1/1 就绪且围栏已释放。控制器恢复不属于系统自主自愈。

实时独立审核未调用：完整审核快照为 13,686 字节，超过原 12,000 字节输入上限。对保存的真实观测进行只读重放时，重建快照为 13,882 字节；将输入上限调整为 16,000 字节后，完整材料进入独立模型审核，收到了完整结束凭据，候选假设复核完成。一次重放仍因模型引用的对象不完整，类型化缩零证据检查返回 `cited_objects_incomplete_or_ambiguous`。重放不改变原调查结果、不授权动作，也不能代替实时验收。

代码将输入预算与审核输出预算拆分：输入最多 16,000 字节，审核输出仍最多 12,000 字节，完整提示仍受 32,000 字节上限约束。超过边界、证据被省略、结果不完整或缺少模型完成凭据时继续阻断，不截断证据后当作已完成审核。远端无网络隔离容器中专项回归 482 项、完整回归 2423 项通过，JavaScript 语法检查通过。受控回归覆盖新增输入区间、超限拒绝、输出上限及原有身份和引用门禁；合成测试不计作真实故障结果。

本次只观察到一次非生产真实故障和一次受控恢复，不提供总体准确率或性能结论。实际自主恢复还需要实时独立审核与完整对象引用、达到诊断置信度要求、同范围真实历史、规则授权、审批条件及业务验证全部满足；真实闭环验收尚未通过。没有修改生产部署。
