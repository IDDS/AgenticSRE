# RCA 证据评审与三服务传播验收

## 范围

本轮针对可信根因推荐中的质量评审缺口。所有测试、容器和实际故障实验均在
远端 snail 执行，本地只编辑、保存材料和提交代码。沿用正式系统当前 LLM
配置，未使用聊天中历史密钥。真实实验隔离命名空间、应用数据和端口，自愈关闭。

输入为三服务真实 HTTP 调用、实际 Pod 日志、挂载配置及 OTLP/Jaeger Trace。
这是受控故障验收，**不是自然生产事故准确率，也不是新的 Prometheus 告警
压缩率实验**。不据此宣称原设计全部完成或达到 1000× 压缩。

## 已复现的问题

正式镜像 `agenticsre:knowledge-publish-20260921` 的完整实验
`agenticsre-propagation-0530f1f7` 耗时 495.44 秒。10 项门禁中 9 项通过：
Pipeline 完成、Trace、目标 Pod 日志、根因组件、精确 namespace/Pod、实体
实测校验、FAILED 状态变化、同 change_id 的 503 请求、预算未耗尽。
健康和恢复阶段均不输出根因候选，原始输入完整保留。

唯一失败为质量评审：旧综合分 0.609，门槛 0.65。模型评审给出 level 0，
但 161 字推理的措辞/长度规则仅得 0.348。更直接的远端反例：没有 LLM 时，
简短观测陈述得 0.234，重复肯定措辞的虚构磁盘故障得 0.952 并通过。
因此问题不是简单调低阈值，而是原质量门禁把文风作为证据的替代品。

## 修复行为

初次评审和补证后的再次评审均接收 `session.evidence` 中的结构化观测。
按 Agent 轮询取样，保留来源、对象、时间及 raw_ref，分配 E1 等引用 ID。
评审结果保存实际送审的有界证据快照，以便重新定位引用。
汇总文字、失败采集、重复的 structured_evidence 容器不作为独立事实。
最多 32 项、约 16000 字符；单项观察截取 3000 字符并标记截断。

模型必须提供实际证据引用、未支持的实质性主张和未解决的矛盾。服务缺失、
调用失败、非法评分、空/不存在的引用、缺乏观测或存在未支持主张/矛盾时，
都要求人工复核。提示明确将日志和报告视为不可信输入，不能执行其中的指令。
引用存在只证明可追溯，不自动证明因果或日志真实。
非法模型输出不原样进入返回值：NaN 等异常替换为稳定错误对象，避免复核
结果在 API JSON 序列化时再次失败。此路径以严格 JSON 编码断言复现：补丁前
1 failed / 16 passed，补丁后最终全量回归通过。

评分采用证据、逻辑、具体性、可操作性四维最低值，并受模型等级上限约束
（0/1/2/3 对应 1/.75/.5/.25）。阈值仍为 0.65，评分语义已改变，不能把
新旧分数当作同一标尺比较。旧语言规则只保留诊断显示；`judge_llm_weight`
保留配置兼容，但不再参与此门禁。没有观测的旧接口调用同样不能自动通过。
该分数不是经过独立事故样本校准的正确概率。

## 回归与真实模型核验

新增 17 项测试，旧镜像 17 failed，修复镜像 17 passed。覆盖简短有依据结论、
措辞不影响分数、伪造/缺失引用、矛盾、缺证据、非数值/NaN/布尔评分以及
模型不可用等。全量首次运行为 **961 passed / 211.06 秒**；最终含引用快照
和异常 JSON 防护版本为 **961 passed / 208.44 秒**。

真实模型使用现场采集的观测进行正负结论复核，标签由实验状态与明确的错误
主张确定，不由被评审模型自标注。案例包含正确状态变化、虚构磁盘损坏、
否认实测故障、编造操作者、缺证据、错误 namespace、倒置因果方向和日志
指令注入。8 类各两次，**16/16 符合预期**。重复测试仅用于检查稳定性，
不视为独立事故样本。对旧版原始报告直接补充现场观测回放，新评审得分 0.80，
无须修改结论、延长推理或添加肯定措辞；引用快照验证通过。

## 完整现场实验

修复版命名空间 `agenticsre-propagation-df45e453`，完整 Pipeline 耗时
**405.91 秒，10/10 门禁通过**。包括源 Pod 的 FAILED false→true 状态日志、
同 change_id 的 FAILED=true / HTTP 503 请求、Jaeger 传播、精确实体和
manifest 实测身份校验。质量得分 0.90，阈值 0.65，无未支持主张或矛盾，
9 个证据引用。健康和恢复阶段均拒绝生成根因候选，原始输入完整保留。

本轮指标 Agent 没有可用结论；日志、配置与 Trace 构成接受结论的依据，
不能宣称所有遥测来源均已验证。模型阶段仍发生一次调用超时，总预算未耗尽，
不能称为无超时系统。置信度校准输出 0.927，尚不是实证校准的正确概率。

完整现场实验使用修复评审算法；其后正式镜像仅补充 `review_evidence` 快照
输出、非法模型 JSON 的错误对象归一化与对应断言，不改变有效评审的评分算法。
最终镜像重复通过 16 个正负案例和上述原报告实证回放。
