## 修复内容

1. 删除多智能体固定 Skill 桥接阶段和规划提示中的 Skill 指令。工具注册默认不暴露 Skill，旧 `enable_agent_skill_bridge=true` 不能恢复该能力；多智能体拒绝显式 Skill 工作流和带 Skill 的外部工具注册表。任务使用独立注册表。
2. 指标查询按 namespace 过滤并复核返回标签，改为有界时间范围查询，保留原始样本、标签和查询语句。未绑定节点的 namespace 诊断不混入全局节点指标。空摘要或模型异常明确标记失败，同时保留已经采集的证据；外部取消正常传播。
3. 指标、规划、假设、关联和协作评审采用有界输出，DeepSeek 支持的短调用关闭独立思考模式。保留模型调用期限和人工复核门禁，不用无限延长超时代替修复。
4. 状态变化按原始应用日志时间排序，保留 before、after、field、change_id。最终状态时间线由这些记录生成，不使用模型猜测时间。时间线明确仅覆盖观测到的应用状态变化。
5. Critic 缺字段、类型不合法或调用失败时要求人工复核。报告改写必须包含根因实体；遗漏时拒绝用不完整报告替换原结论，并记录复核原因。
6. 多个智能体的结构化证据交替保留，避免大量指标占满前 100 条而挤掉日志或事件。
