# 跨指标归并建议与显式审核流程

## 本轮范围

原有 SCAG 的 `evidence_supported` 不等于根因确认，也不能授权自动合并。此前虽然已有人工合并接口，但通过证据检查的关系与该入口之间缺少可审查的建议视图。

新增 `agents/alert_merge_review.py`，在 SCAG 构建后产生两组之间的建议。仅接受完整实时扫描、有效时间窗、同集群/命名空间/对象/维度、firing 的 Prometheus 告警、不同测量查询及匹配的实时指标证据；关系必须为 equivalent/shared_root，且结构、时间、统计检查全部通过。任何矛盾关系优先阻止建议；缺证据、过期、人工编辑和导入数据均不产生建议。

建议不改变分组、原文、严重度、生命周期或压缩率；两条建议共享一个组不意味着三组可以整体合并。前端展示依据、指标引用和不确定性，选择按钮只选择两组并聚焦原因输入框，仍通过既有人工合并入口执行。证据到期时按钮禁用，编辑后建议失效。前端缓存版本更新至 app.js?v=138。

这补齐了辅助审核流程，**没有完成自动跨指标归并，也不代表原先 9→3 目标通过**。
