# 告警压缩效果修复与远端复验

## 修复内容

本轮针对远端效果审计发现的真实误合并、模板覆盖不足、语义候选噪声和证据包开销进行了修复。

1. **Job 身份与告警维度。** `job_name` 作为 Kubernetes Job 身份，优先于 kube-state-metrics 采集器 Pod；不把 Prometheus 的 `job` 抓取标签当作 Job 名。分组键保留 condition、container、reason 等标签差异，仅允许严重度及明确的瞬态字段变化。同一 Job 的重复通知仍可合并。历史扫描中使用采集器身份的 Job 组进入诊断时被拒绝，接口返回 409，要求重新扫描；旧原文保留。
2. **历史基线兼容。** 分组签名升级为版本 2，历史计数只与相同版本比较。旧版本快照保留，但不参与新版本排名；新版本需积累至少 3 个历史时间桶后才显示 ready，避免把签名变化误报成新增告警。
3. **保守模板扩展。** 识别明确的 `request UUID/长十六进制 ID` 及 `after/waiting 数值 ms/milliseconds`，保留 HTTP 状态码、否定词、版本、目标 UUID、业务路径和原始文本。没有把所有数字统一抹除。
4. **语义检索输入。** ApplicationLog、Log、Logs、unknown 等通用名称在有正文时不参与向量输入，避免标题掩盖正文差异；有意义的告警名称仍保留。
5. **紧凑证据包。** RCA 默认使用精简投影，去除重复对象、单一严重度记录、已被样本覆盖的重复 ID、空统计和未知基线等。保留来源与版本、样本、峰值、实际变化、有效统计及关联证据。Python 接口可用 `compact=False` 获取完整投影，原始扫描仍全量保存。

| 401 条支持的动态日志 | 5 | 5 | 98.75% |
| 601 条指标与峰值 | 3 | 3 | 99.50% |

通用模板同族记录对召回率从 62.5% 提高到 87.5%，误合并对数仍为 0。剩余 50 条不同订单路径保持独立，需要明确的路由模板或业务语义，不能仅为提高压缩率而自动删除路径差异。

四组回放均无原文遗漏，30 条 critical 告警及样本全部保留，2/2 个指标峰值保留。通用模板的全部证据包从 238848 字节降至 54166 字节，相比原文 84972 字节减少 36.25%；此前为原文的 2.81 倍。重复通知、动态字段和指标证据包分别较原文减少 85.04%、87.56%、96.73%。这些是序列化 UTF-8 字节，不是 Token 数或磁盘压缩率。

使用实际 all-MiniLM-L6-v2 模型的固定 4 描述探测，保留数据库连接问题的正确候选，原来 2 对无关候选降至 0。该小样本不能推导生产召回准确率。

## 限制

紧凑投影降低了开销，但不保证每个小组的证据包小于原文。关联图、引用和统计也占上下文空间；仍需按真实 RCA 请求测量 Token 与按需取证预算。不能声称已经实现任意场景的固定压缩倍数，也不能将这些受控结果当作生产根因准确率。
