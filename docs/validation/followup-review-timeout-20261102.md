# 补证后独立审核超时与真实复测

上一次真实故障实验中，首次独立审核 7.484 秒完成，补证后的最终审核在 8 秒上限处超时。现将最终审核的请求上限设为 20 秒，且不超过系统配置的更短超时；仍禁用重试并要求提供方完整结束凭据。远端隔离测试通过 828 项定向测试、2573 项完整测试及页面渲染检查；测试覆盖更短配置和迟到结果不能通过门禁。

在非生产环境对单副本业务 Deployment 进行真实缩零。基线 20/20、故障期 0/5，对照健康。诊断报告空端点和零副本；首次和补证后的独立审核分别在 7.846 秒、8.762 秒取得完整结束凭据。候选复核仍存在未核实的排除断言，自动恢复被阻断，实验控制器恢复业务；恢复后连续三个窗口各 10/10，对照健康，目标 1/1 且围栏释放。

本次还观察到审核角色将模板标签匹配和零副本误称为支持选择器不匹配假设。虽然其他候选阻断了整体自动动作，这一机制判断仍需进一步增加类型化证据约束。实验没有证明整体诊断准确率，也没有完成自主恢复验收；生产实例未替换。
