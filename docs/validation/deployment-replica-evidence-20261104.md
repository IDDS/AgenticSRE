# Deployment 副本字段证据

事件采集原先将 Deployment `spec.replicas` 缺失、`null` 或其他假值通过默认值转换为零，可能产生错误的缩零证据。现在只将明确的非负整数作为副本数；缺失、布尔值、字符串、负数或其他无效值均保持未知，不能生成零副本信号。对真实零值的证据明确标出字段来源 `spec.replicas`，但此状态不证明谁修改了副本数或修改原因。

远端隔离环境中 148 项相关回归通过，另有 4 条依赖弃用警告；覆盖字段缺失、无效类型与显式零值。非生产真实缩零试验中，实际 EventAgent 采集到目标 Deployment UID、资源版本和来源为 `spec.replicas` 的零值，同时采集到关联 Service 的端点状态；目标和对照业务在控制器回退后的三个窗口各 10 组检查成功。试验由独立看门狗保护，属于检测和证据采集验证，没有运行完整模型诊断或自主恢复，不证明总体定位准确率或验收通过。
