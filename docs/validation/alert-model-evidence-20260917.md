# 实测指标进入语义提议与证据使用审计

## 问题与修复

此前实时指标已用于嵌套阈值归并和 SCAG 统计验证，但 `propose_relations` 的模型输入只有告警样本、对象以及 Trace/变更上下文，没有指标证据。这是输入链路缺口；不能据此推断补齐输入必然能完成跨指标事件压缩。

新增 `agents/alert_model_evidence.py`：仅接受未被人工编辑的实时扫描、来源为实际 Prometheus 规则且对象和成员完全匹配的 ready 证据。向模型提供规则、测量查询、窗口、覆盖率、首尾值、全窗口极值和统计验证摘要。原始采样仍保留在证据包中。导入数据、失配成员、失配对象和非有限数据不获得有效测量上下文。

语义报告新增 `metric_context_pairs`、`trace_context_pairs`、`change_context_pairs`，用于区分采集器被调用与证据实际进入候选输入。新增 `returned_relations` 和按原因分类的 `rejected_relations`，区分模型返回空数组与引用不合法而被过滤。既有接受条件和归并授权条件未改变。

拓扑目前主要在模型提议后的 `build_scag` 中用于关系验证；Trace 则同时参与候选召回、模型上下文和关系验证。已有真实 HTTP/Jaeger 连续 Span 验证见 [内部 Span 衔接验收](alert-spanbridge-20260916.md)，该实验使用显式假设、没有模型调用，不能作为自主 RCA 或本轮阈值压缩的证明。
