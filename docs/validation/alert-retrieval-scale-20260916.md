## 范围与当前状态

本轮补齐语义检索默认只处理前 256 组的缺口。代码和候选镜像在远端 `snail` 的独立实例验证；生产版本尚未替换。费用、Token 与调用预算暂不作为功能验收约束，本轮没有新增预算控制功能。

默认将所有压缩组送入检索。256 组以内保留原精确计算路径；大批量使用分范围的词法倒排及向量检索，同一集群/命名空间最多 512 个有效组时精确选择向量邻居，更大范围采用 Chroma HNSW 近邻索引。相同向量只有在查询范围和时间过滤条件完全相同时才复用查询结果，各组身份和原文仍分别保存。显式传入 `max_groups` 的调用仍保留截断语义。

`indexed_groups`、`embedded_groups`、`queried_groups` 分别表示进入检索、实际生成向量和被查询结果覆盖的组数。`ann_query_vectors` 是复用后实际 ANN 查询向量数，不是组数；`exact_query_vectors` 记录精确查询向量数。`candidate_pairs_truncated` 单独报告输出候选对的截断，避免将全量索引误解成全量关系验证。

## 发现并修复的问题

初版万组实际检索耗时 36.41 秒，触发旧 API 的 30 秒时限并降级；其中向量生成 0.87 秒，索引与查询 31.70 秒。相同查询复用后，最终万组 API 实测为 18.47 秒，向量检索覆盖 10,000/10,000，未降级。

新增纯向量尾部反例曾在全量回归中失败：HNSW 在大量重复向量中可能遗漏孤立邻居。没有放宽断言；小范围改为精确检索，避免在这类规模下引入不必要的近似误差。更大范围仍标注 `approximate=true`，不保证穷尽所有关联。

另用 1,000 种不同文本实际生成向量，直接检索耗时 30.10 秒，其中向量生成 28.34 秒。重复模板压力测试不能代表不同文本的推理成本，因此将 API 响应保护时限放宽到 120 秒，保留显式超时降级和隔离后台结果的机制。这是响应保护，不能解释为所有负载都保证在时限内完成。

## 验收结果

最终候选完整回归 **633 passed，106.99 秒**，相较此前 628 项增加 5 项检索规模测试。定向测试 20 项通过。现有 pytest/依赖弃用警告仍存在。隔离测试容器已清理，生产主服务与 Skill runtime 仍运行原镜像且 healthy。

- 万条重复通知：10,000 → 100 组，3.791 秒。
- 万条独立对象：10,000 → 10,000 组，18.472 秒，向量及查询覆盖均为 10,000；该数据只有一种检索文本，不能代表万种不同文本。
- 千种不同文本完整 API：1,000 → 1,000 组，32.967 秒，实际向量和查询覆盖均为 1,000，未降级。
- 上述 API 均完整保留原文；两组万条验收未发现误合并，高危组完整可见；10,001 条仍明确拒绝。
- 0、1、20、256 组旧版对照结果完全一致。新增测试包括模型和索引故障降级、范围与时间边界、尾部召回和候选输出截断。

这些是受控样本的实际远端测量，不是生产标注集准确率、P95 或并发 SLA。尚未测试万种不同文本的完整 API。

## 原设计完成度的判断边界

| 原设计内容 | 当前可支持的结论 | 仍需补齐或验收 |
| --- | --- | --- |
| 统一事件、保留原文、模板与指标压缩、异常排序、证据包 | 已实现，已有 22,624 条受控样本与真实 Job 生命周期验收 | 生产人工标注集与长期误合并观测；频率偏移需要有效历史基线 |
| 本体、关键词、Embedding Top-N | 本轮候选取消默认 256 组索引上限，并进行远端实际向量验证 | 大范围近邻召回质量；更大规模不同文本及并发负载 |
| 结构化语义关系与 SCAG 三重检查 | 已有代码与边界测试，候选边不会直接变成因果结论 | 默认输出最多 200 对、LLM 当前最多检查 20 对，尚非全候选验证 |
| 假设生成、工具取证、反证与停止判断 | 已有诊断链路和真实 Job 验证，证据不足时保留不确定性 | 原图要求的完整树搜索、阶段归因与局部修复能力需逐项专项验收，不能由 Job 单场景推定全部完成 |
| 根因、传播路径、SOP 等输出 | 已有输出与证据引用；Job 退出机制经过实际验证 | 当前 Trace 快照没有匹配目标调用链，未完成真实因果传播路径验收；置信度数值不等于已在生产集上校准 |
| 人工反馈、记忆、持续演化、数字孪生与过程指标 | 项目已有部分模块与故障注入测试 | 尚无证据证明整张设计图所列能力作为统一闭环全部完成；不能将故障注入等同于完整数字孪生 |

本轮不声称“原设计全部实现”或“没有问题”。后续优先补齐语义验证覆盖和真实多源因果链证据，再做完整设计的逐项验收；预算优化暂缓。
