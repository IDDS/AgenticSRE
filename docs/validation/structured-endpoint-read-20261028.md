# 命名 Endpoints 结构化采证验证

此前一次真实缩零故障中，通用采证 Skill 除已有结构化读取外，还执行了模型提出的无输出格式命名 Endpoints 查询。该查询返回人类可读表格，缺少可核验 UID 和资源版本；独立审核因此保留 `unreviewed_tool_output` 并阻断。旧表格不能被重放补造成结构化证据。

本轮仅在服务拓扑采集已启用、命名 Endpoints 与目标 Service 完全一致，并且命令除命名空间外没有其他参数时，将该读取改为已有 `service-evidence/v1` 固定字段投影。实际执行的命令及采集结果仍保存在工具轨迹；宿主检查协议末尾标记，保留对象身份、资源版本、端点状态和采集时间。不能从缺失字段或文本摘要推断健康或根因。

显式输出格式、选择器、watch、多个对象、其他目标、重复命名空间及其他参数均不进行此转换；原有只读权限和范围检查不变。针对这些场景的受控回归、宿主投影解码和观测保存检查均在远端进行，合成测试不是故障注入，也不授权动作。

最终候选在远端无网络隔离容器中专项 649 项、完整回归 2457 项及 JavaScript 语法检查通过。另对非生产集群执行一次只读命名 Endpoints 读取：改写后的查询经宿主解码形成带时间的观测，UID 和资源版本与集群独立读取一致；该检查没有注入故障。

随后进行一次有独立看门狗的非生产真实缩零：基线 20/20 成功、故障期间 0/5 成功，对照健康；诊断 22.465 秒完成并匹配实际目标。模型本次选择的是显式 JSON 的 Endpoints 查询，没有在故障期间触发本轮默认格式转换；同时产生的 Service 描述和事件文本仍不能被独立审核完整覆盖，因此审核未调用、自动恢复阻断，真实自愈动作数为零。实验控制器恢复后，业务连续三个窗口各 10/10 成功、对照健康；原 Deployment 恢复 1/1 且围栏释放。控制器恢复不属于系统自愈。

真实自主闭环尚未通过验收，仍需处理未覆盖的工具输出、独立审核及后续动作门禁。脱敏[验证摘要](evidence/structured-endpoint-read-20261028.json)保存了关键结果和远端原始记录哈希；不根据这些单次实验推断总体准确率或效率。
