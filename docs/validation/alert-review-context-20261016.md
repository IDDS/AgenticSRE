# 审核前事故轮次与证据时效验证（2026-10-16）

## 本轮交付

在[审核观测候选](alert-review-observation-20261016.md)基础上，新增 `ReviewContextGuard`，通过实际 Web 作业 worker 接入审核前的生命周期只读快照和每批审核前后复核。新任务的准备快照保存事故轮次与版本；中断恢复沿用原快照，不重新绑定到后来发生的事故。

本轮继续保留 `reuse_allowed=false` 和 `reused_pairs=0`。这是跨扫描复用条件的补齐，尚未启用旧答复代替新模型调用。没有提交、推送或部署，生产数据未运行迁移。

## 事故轮次与并发变化

原生命周期在审核完成后的发布阶段更新，审核前直接读取旧 episode 可能把“恢复后再次触发”归到旧事故。本轮使用 SQLite `mode=ro`、`query_only=ON` 和单个读事务，读取涉及的 incident 与采集水位；不调用创建表的连接方法，不推进生命周期，数据库缺失时也不创建目录或数据库。缺失、异常或读取锁超时只产生明确的不可验证状态。

仅完整、无降级的可信 `live_scan` 可以进入验证。导入接口的 payload、原文中的来源声明或伪造的 `review_context` 都不能取得 worker 的可信来源；新任务准备时由服务端生成投影。旧 prepared 文件没有投影时，不推断历史事故身份。

投影核对集群、命名空间、来源、incident ID、episode、episode 开始时间、状态和采集水位。首次出现、已恢复/过期后重现、正在等待恢复、乱序/重复扫描和未知来源均不可用于复用判断；不会预猜新 episode。读取版本覆盖相关 incident 完整状态及相关水位，审核期间发生同一 episode 的其他更新也会使版本复核失败。

完整原始成员都进入投影，包含组中未作为提示样本的成员。重复成员使用相同 incident 时，其完整状态只计算一次版本摘要。新增测试验证 1,002 个原始成员全部覆盖，并能发现末尾首次出现的 incident。

每批开始前和成功/失败 checkpoint 保存后各复核一次。原本通过校验、但审核期间发生生命周期变化或证据过期的成功记录标为 `invalidated`，清除其匹配键；本次审核结果和原文仍按原流程保存，不宣称模型结论因此获得因果认证。

跨扫描匹配身份使用 episode 指纹，单次读版本和检查时间只作审计记录。关键回归用例让审核请求字节和完整成员证据摘要保持相同，经历“告警消失—生命周期结束—再次出现”后 episode 从 1 变为 2，验证旧审核不再匹配。该测试在隔离数据库执行，不是实际集群故障注入。

## 时效规则

时效采用已有扫描 `time_window`，上限为 300 秒，作为当前观测策略；它不是已批准的生产缓存 TTL。截止时间取采集开始及实际使用的来源时间中最早者加上该窗口，不会因重试、读取或记录时间变晚而延长。

- Prometheus 告警使用原始向量 `value[0]` 的采样时间；采集器本机打上的 `timestamp` 不足以证明来源数据新鲜。
- Kubernetes 事件使用采集时解析出的事件时间；事件过期不能宣称业务恢复。
- 实际进入提示的指标摘要核对查询结束与最后样本时间；复合指标逐个核对，历史序列起点不被误当成“最后观测时间”。
- Trace 引用和传播路径逐段核对来源与时间；缺失、歧义或被截断的来源不能通过时效判断。变更引用同样核对来源、时间和截断状态。
- 缺失、非有限、未来时间或窗口到期均明确阻止该记录参与匹配；时钟回拨导致捕获时间落在未来时拒绝验证。

这些规则是对已保存证据及当前生命周期的复核，没有在审核循环里重新请求 Prometheus、Kubernetes 或 Jaeger。它们也不能替代租户/访问范围版本和供应商实际模型版本的保证。

## 状态与兼容性

作业与结果的 `review_observation` 增加 `context_verified_reviews` 和 `invalidated` 类别。前后检查均通过的完整审核才增加验证数量；审核期间失效的记录不再计入此前成功请求的重复数。缺少可信 guard 的独立离线调用继续保留此前的输入重复观测语义，但不会因此获得上下文验证或实际复用权限。

可信 guard 已接入实际异步 worker，覆盖新建实时任务及恢复路径。同步扫描暂未接入此观测机制。旧任务、导入任务和读取故障仍可以完成正常审核、保存原文；它们不会被当作已验证的可复用来源。

当前仍保留 `access_scope_unversioned`、`provider_completion_metadata_unavailable`、`model_revision_missing`（未显式声明时）及 `reuse_disabled`。此外仍需明确历史观测留存、真实 token 计量和独立事故质量验收。
