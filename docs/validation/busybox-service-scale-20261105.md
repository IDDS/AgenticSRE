# 轻量服务实例规模短时试验（2026-11-05）

在非生产集群中，按 AgenticSRE 可见且被就绪 Service EndpointSlice 引用的去重 Pod UID 统计服务后端。试验前有 129 个既有后端（包含配套服务）；在独立临时命名空间逐批创建 174 个 Kubernetes Service，各绑定一个 BusyBox HTTP Pod。新增服务使用相同实现，每个 Pod 请求 1m CPU 和 8 MiB 内存，限制为 50m CPU 和 24 MiB 内存。

分批就绪后的总数依次为 130、154、204、254、303。最后三次清点均为 303，首末相隔 48.0 秒；执行器记录逐个检查 174 个测试 Service 的 HTTP 响应成功，但未单独保存逐条响应。试验中仅以节点资源和就绪状态保护执行，不对新增实例启动诊断或逐个开展监控分析。

结果页生成发生格式错误，原执行器整体状态为 `failed`；已独立核对保存的清点记录，确认 303 个 UID 不重复、新增后端各对应一个不同 Service。临时命名空间已验证清理；清理前后商城、酒店和铁路业务检查各 5/5 成功。前两次试验分别因空端点处理和节点监控采样不完整而中止，均已清理。

303 超过原始数量阈值，但其中 174 个测试服务使用同一种 BusyBox 实现，既有后端包含配套服务，不能表述为 303 种业务或 303 台服务器。三次观察跨度约 48 秒，未达到此前建议的五分钟稳定观察；实例定义、持续时间和正式验收结论需测试方确认。原始记录和截图保存在私有测试材料中。
