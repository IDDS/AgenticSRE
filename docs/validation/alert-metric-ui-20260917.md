# 告警指标证据前端展示

## 页面变化

通算告警的压缩扫描结果新增“实时指标取证”概览，分别展示已取得、不适用和待补证的分组数量。每个事件组新增可展开的指标证据详情：取证状态、缺失原因、规则表达式、实际查询、序列标签、规则适配版本及中文测量含义、时间窗口、步长、时间网格覆盖率、证据 ID 和历史样本表格。

Watchdog 显示“不适用业务指标取证”和恒定心跳原因；恒定序列的统计说明显示“历史数值恒定，无法判断统计相关性”。关联检查展示指标证据引用。分组编辑后隐藏旧分组证据并提示重新扫描；旧扫描没有指标证据时明确显示暂无记录。

样本表每组最多展示前 100 点并明确提示，避免大结果压垮页面。查询、标签、适配说明等动态文本统一 HTML 转义。长查询自动换行，样本区可滚动，详情使用原生 details/summary，表头提供列语义。HTML 中 JS/CSS 版本参数已更新，避免旧缓存遮蔽发布。

## 验证方法

仅在远端 snail 测试。只读采集现网告警和指标、构建关联证据，保存为 `live-ui-evidence.json`，通过实际候选页面的渲染函数展示此真实快照。浏览器验收覆盖展开规则/查询/样本、Watchdog 原因、手机宽度、旧记录、编辑后失效提示以及带 HTML 的查询文本转义；后几项使用明确构造的边界数据。这不是在生产点击扫描或制造新告警。
