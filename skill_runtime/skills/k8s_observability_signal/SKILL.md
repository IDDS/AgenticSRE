# K8s 可观测性信号诊断与守护式处置

本 Skill 用于检测指标异常、TargetDown、时延升高与日志错误激增，并提出受控的排查与处置建议。

## 适用场景

- Prometheus 指标出现异常突增、骤降或阈值告警。
- 采集目标 `TargetDown`，抓取失败或 scrape 超时。
- 服务 P95/P99 时延升高、错误率上升。
- 日志中 error/exception 数量出现明显激增。

## 输入信号

- Prometheus 告警与 PromQL 查询结果。
- ServiceMonitor/Target 抓取状态与 `up` 指标。
- 应用日志错误计数与关键异常堆栈。
- 相关 Pod/Deployment 的资源指标与事件。

## 执行阶段

- `detect`: 识别异常信号类型，确认为可观测性事件。
- `diagnose`: 关联指标、抓取状态与日志，判断是采集侧问题还是真实业务劣化。
- `verify`: 审批执行后确认信号恢复正常水平。

本 Skill 不执行重启、扩容或 exporter 修复；相关动作由下游恢复 Skill 生成并经过门禁。

## 风险与门禁

- 风险等级 medium，重启操作可能影响服务，必须人工审批。
- `requires_approval=true`，`safe_auto_execute=false`。
- 至少需 1 个证据来源即可进入诊断，但结论应尽量交叉验证。
- 进入自愈门禁所需的最低校准诊断置信度为 0.72，全自动执行门槛为 0.95；两者均不表示恢复成功概率。

## 验证方式

- 相关指标回落至基线区间，告警解除。
- `up` 指标恢复为 1，Target 抓取成功。
- 服务时延与错误率回归正常，日志错误激增停止。
- 无新增同类可观测性告警。
