# 通用风险门禁

本 Skill 作为恢复动作的安全门禁，负责审批校验、回滚可用性检查与 dry-run 强制执行，保障变更安全。

## 适用场景

- 恢复动作执行前需要进行安全性与合规性校验。
- 需要判断动作是否要求人工审批。
- 需要确认回滚方案是否可用。
- 需要对高风险动作强制 dry-run 预演。

## 输入信号

- 待执行恢复动作及其风险等级。
- 主诊断置信度与证据来源数量。
- 目标资源的爆炸半径与影响范围。
- 策略配置：审批要求、回滚能力、dry-run 开关。

## 执行阶段

- `diagnose`: 依据策略评估审批需求、回滚可用性与置信度门槛。
- `heal`: 对通过门禁的动作放行；对不满足条件的动作拦截并要求审批或 dry-run。

待评估动作由上游恢复规划提供；门禁结果写入审计轨迹，后续恢复验证不由本 Skill 执行。

## 风险与门禁

- 风险等级 low，仅使用 `policy.read` 只读权限。
- 门禁自身可自动运行，但不替代具体恢复动作的审批。
- 置信度低于 0.6 一律拦截。
- 低于 0.9 禁止自动放行，须人工审批。
- 无可用回滚方案时强制拒绝或要求 dry-run。

## 验证方式

- 检查门禁决策是否输出放行或拦截结论及理由。
- 校验审批与回滚判定是否符合策略配置。
- 确认高风险动作是否被强制 dry-run。
- 保留决策日志以供审计追溯。
