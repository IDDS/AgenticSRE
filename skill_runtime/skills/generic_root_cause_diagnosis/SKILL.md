# 通用根因诊断

本 Skill 作为通用根因分类器，将症状与证据映射到可能的基础设施、应用、LLM 或依赖类根因。

## 适用场景

- 证据齐备后需要产出结构化的候选根因。
- 跨领域故障需要统一的根因分类框架。
- 为诊断融合提供带证据链的候选根因。
- 需要区分基础设施、应用、LLM 与外部依赖类问题。

## 输入信号

- 症状清单与故障上下文。
- 采集到的指标、日志、事件证据，至少 2 个来源。
- 拓扑与依赖关系信息。
- 历史相似案例与规则命中结果。

## 执行阶段

- `diagnose`: 将症状与证据映射到候选根因类别，输出置信度与证据引用。

症状和证据由上游检测与采集 Skill 提供；本 Skill 只产出根因诊断，恢复与恢复验证由下游 Skill 完成。

## 风险与门禁

- 风险等级 medium，`requires_approval=true`，`safe_auto_execute=false`。
- 至少需 2 个独立证据来源方可分类。
- 置信度低于 0.75 不进入 heal；低于 0.92 禁止自动恢复。
- 根因结论须经审批后方可驱动变更。

## 验证方式

- 检查候选根因是否带类别标签、置信度与证据引用。
- 校验证据来源数量是否满足门槛。
- 确认未在未审批情况下触发变更。
- 对照专家确认的真实根因或带 ground truth 的评测样本统计分类准确率；恢复验证结果只评价处置动作，不作为诊断正确性的替代标签。
