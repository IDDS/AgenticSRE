# 前端浏览器验证工具

本 Skill 用于从用户视角验证 AgenticSRE 前端是否可用，特别适合演示前、部署后和前端回归后检查告警中心、智算事件中心、GPU Lab、Skill Catalog、RCA 工作流弹窗等关键页面。

## 适用场景

- 用户反馈“前端没有变化”“按钮点了没反应”“弹窗打不开”。
- 演示前需要确认通算告警、智算事件、Agent+Skill 分析、自愈分支、故障报告详情可以点击和展示。
- 远程部署后需要通过浏览器验证页面不是只靠 API 健康。
- UI 布局出现重叠、内容过多、图表空白或依赖图加载失败。

## 输入信号

- 前端 URL，例如 `http://127.0.0.1:18080`。
- 需要验证的页面或入口，例如告警中心、智算事件、GPU Lab、Skill Catalog。
- 需要点击的动作，例如启动 Agent+Skill 分析、打开 RCA 工作流、展开 Skill 调用细节。
- 可选的登录态、用户名、只读测试账号和期望的页面文本。

## 执行阶段

- `detect`: 识别前端可用性、演示验证、浏览器点击、截图、弹窗、页面回归等需求。
- `diagnose`: 生成浏览器验证计划；如果部署侧注入 browser/playwright 工具运行器，则执行只读页面访问和点击检查。
- `verify`: 给出复测清单，包括页面状态、关键按钮、弹窗、工作流、图表和错误提示。

本 Skill 不修改页面、提交表单或部署修复；发现的问题交由开发或下游恢复流程处理。

## 风险与门禁

- 风险等级 low，默认只读验证。
- 不提交真实写操作，不保存密码，不上传文件，不触发危险自愈。
- 涉及真实故障注入、真实自愈或外部数据传输时，必须由上层 Agent 另行审批。
- 没有 browser/playwright 工具运行器时，只生成验证计划，不声称已真实点击页面。

## 验证方式

- 浏览器能够打开目标 URL，页面返回 200 或可见登录页。
- 关键导航和按钮可点击，弹窗可打开并可关闭。
- Agent+Skill 或多智能体分析启动后有运行状态、过程事件和最终结果。
- 截图或 DOM 摘要能证明页面无明显空白、重叠或核心内容缺失。
