# 知识检索

本 Skill 从知识库与历史记录中检索相似诊断规则、历史 RCA、专家反馈与恢复结果，为诊断与恢复提供上下文。

## 适用场景

- 诊断阶段需要参考历史相似案例与既有规则。
- 恢复前需要查阅同类故障的成功恢复动作与失败教训。
- 需要引入专家反馈以校准置信度。
- 为诊断融合提供历史置信度基线。

## 输入信号

- 当前故障症状、疑似根因与领域标签。
- 检索关键词、组件名与错误特征。
- 时间范围与相似度阈值。
- 知识库与本地文件路径，只读。

## 执行阶段

- `diagnose`: 检索相似规则、历史 RCA 与专家反馈，按相似度排序并返回引用。

检索意图由上游编排器提供；历史恢复动作和验证判据仅作为诊断输出中的引用，不代表本 Skill 执行恢复或验证。

## 风险与门禁

- 风险等级 low，仅使用 `knowledge.read` 与 `filesystem.read` 只读权限。
- `requires_approval=false`，`safe_auto_execute=true`。
- 仅检索与读取，不写入知识库，不执行变更。

## 验证方式

- 检查返回结果是否带来源引用与相似度分数。
- 校验检索范围是否受限于只读路径。
- 确认无写入或修改知识库的操作。
- 对无命中情形返回明确的空结果与降级建议。
