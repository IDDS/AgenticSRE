# 数据库连接池诊断工具

本 Skill 是只读的数据库连接池诊断工具，针对连接饱和、超时与锁等待等症状进行排查。

## 适用场景

- 出现数据库连接超时、连接池耗尽或获取连接失败。
- 观测到活跃连接数逼近上限或大量等待连接。
- 存在长事务、锁等待或死锁导致连接堆积。
- 需要在不改动数据库的前提下定位连接池瓶颈。

## 输入信号

- 数据库实例、库名与连接池配置。
- 连接超时、拒绝连接的错误日志。
- 活跃、空闲、等待连接数指标。
- 锁与长事务信息。

## 执行阶段

- `detect`: 通过 `psql` 或 `mysql-client` 只读查询当前连接与会话状态。
- `diagnose`: 分析连接饱和、超时与锁等待，定位占用连接的会话与语句。
- `verify`: 恢复后只读复查连接数与等待情况是否回归正常。

本 Skill 不终止会话、不修改连接池参数，也不重启数据库。

## 风险与门禁

- 风险等级 medium，仅具备 `db.read` 只读权限。
- `requires_approval=true`，`safe_auto_execute=false`，任何处置需审批。
- 依赖 `psql`、`mysql-client`，须确保只读连接。
- 至少 2 个证据来源，置信度达 0.8 方可建议恢复。

## 验证方式

- 检查查询是否严格只读，未执行写或 kill 操作。
- 校验诊断是否给出占用连接的会话与语句证据。
- 确认恢复建议未被自动执行。
- 复查连接池指标确认问题是否缓解。
